# 🚚 Evden Eve Nakliyat ve Lojistik Fiyat Hesaplama Modülü

Bu açık kaynaklı proje, şehir içi ve şehirler arası evden eve nakliyat hizmetlerinde mesafe, kat durumu ve eşya hacmine göre dinamik maliyet analizi yapan bir fiyatlandırma algoritması içerir. Lojistik firmalarının web sitelerine entegre edilmek üzere geliştirilmiştir.

## 🌟 Özellikler
- **KM Tabanlı Rota Maliyeti:** Google Maps API entegrasyonu ile şehirler arası nakliyat mesafesi hesaplama.
- **Asansörlü Taşımacılık Kat Sayısı:** Kat durumuna göre gereken personel ve asansör kurulum maliyeti optimizasyonu.
- **Sigortalı Nakliyat Entegrasyonu:** Taşınacak eşya değerine göre otomatik sigorta bedeli ekleme.

## 🚀 Canlı Önizleme ve Canlı Entegrasyon
Bu algoritmanın gerçek zamanlı çalışan, optimize edilmiş ve kurumsal standartlara uyarlanmış canlı versiyonunu incelemek ve profesyonel taşımacılık hizmetlerinden yararlanmak için resmi web sitemizi ziyaret edebilirsiniz:

* 🔗 **Canlı Demo & Hizmet Paneli:** [Evden Eve Nakliyat](https://evdenevenakliyat.net.tr)
* 📍 **Bölgesel Hizmet Noktaları:** Şehir içi ve şehirler arası nakliye fiyatlandırmaları için [Evden Eve Nakliyat Hizmetleri](https://evdenevenakliyat.net.tr) sayfasını inceleyebilirsiniz.

## 🛠️ Kurulum ve Entegrasyon

Projenizi yerel sunucunuzda çalıştırmak için aşağıdaki adımları takip edin:

```bash
git clone https://github.com
cd evden-eve-nakliyat-otomasyonu
npm install
npm start
```
